# План визуального обновления UI (без изменения функциональности)

> Цель: повысить общее качество, иерархию и читаемость без изменения бизнес-логики.
> Примечание: подключение и настройка шрифтов пока не выполняются — оставлены только рекомендации по дизайну.

## Диагностика текущего состояния (основные проблемы)

- Нечёткая иерархия: заголовки, секции и кнопки действий имеют близкий визуальный вес, фокус слабый.
- Однообразная вёрстка: единые карточки + сетка без отношения «главное/второстепенное».
- Цвет без направления: почти всё на цветах темы по умолчанию, нет визуального языка «инструмента».
- Панель логов не выделяется: выглядит как обычное текстовое поле, не считывается как «панель системной обратной связи».
- Нет анимаций: запуск и взаимодействия лишены ритма, выглядят жёстко.

## Направление дизайна (рекомендации)

**Тема: Tech Console + лёгкий дашборд**

- Светлый, свежий, серовато-белый фон, подчёркивающий характер «инструмента/консоли».
- Основной цвет — бирюзово-зелёный/бирюзово-синий, вспомогательный — для предупреждений/внимания; избегать фиолетового и тёмных тонов.
- «Ощущение пространства» через лёгкий градиент фона и границы карточек.

### Рекомендации по цвету (примеры)

- Основной цвет: бирюзово-зелёный/бирюзово-синий (напр.: `#0EA5A4` / `#0891B2`)
- Вспомогательный: янтарный/оранжевый (для warning / внимания)
- Фон: светло-серо-белый с холодным оттенком (напр.: `#F8FAFC` / `#EEF2FF` / `#F1F5F9`)
- Карточки: белый фон + тонкая граница + лёгкая тень

### Рекомендации по фону (примеры)

- Направление градиента: `linear-gradient(120deg, #F8FAFC 0%, #EEF2FF 55%, #F1F5F9 100%)`
- Опционально: наложить очень лёгкую текстуру (сетка/шум, минимальная непрозрачность)

### Рекомендации по шрифтам (пока не внедряются)

- Заголовки: `Space Grotesk` / `Sora` (геометричность)
- Основной текст: `Inter Tight` / `IBM Plex Sans`
- Логи: `JetBrains Mono`

## Конкретный план переработки (по модулям)

### 1) Глобальный тон

- Фон: мягкий градиент + лёгкая текстура (не перетягивает внимание).
- Карточки: белый фон, тонкая граница, мягкая тень — для чёткой иерархии.
- Зона заголовка: усилить вес заголовка + добавить подзаголовок (можно позже).
- Шрифты: пока не менять, но зарезервировать трёхуровневую структуру «заголовок/текст/моноширинный».

### 2) Макет и зоны

- Слева «пульт управления», справа «панель состояния» (логи) — контраст главного и второстепенного.
- На больших экранах зону логов справа держать sticky (удобно для постоянного наблюдения).
- Фиксированное соотношение основной и боковой колонок (например 2:1), чтобы колонки не были равнозначны.
- Футер оформить как «панель действий» с акцентом на «запуск одной кнопкой».

### 3) Визуал ключевых компонентов

**ConfigGroupPanel**

- Элементы списка переделать в «сегментированный список + полоса подсветки выбранного».
- У выбранного элемента — светлая полоса фона, зона кнопок собрана справа.
- Разделить основные и второстепенные кнопки: filled / outline / ghost.
- Диалог редактирования фокусируется на содержимом, внешний «шум» рамок ослаблен.

**GlobalConfigPanel / RuntimeOptionsPanel**

- В зону заголовка добавить краткое описание, блоки полей слегка отделить фоном.

**MainTabs**

- Tabs в лёгком стиле с подсветкой нижней границы, контентная зона — единый карточный макет.
- В контенте вкладок поддерживать единые padding и стиль заголовков.

**LogPanel**

- Оформить как «консольную панель»: небольшой статусный бейдж сверху + текстовая зона в терминальном стиле.
- В зоне логов можно добавить очень лёгкую сеточную текстуру для ощущения «системной панели».
- Сохранить моноширинный стиль в зоне логов, но пока без подключения шрифтов.

**FooterActions**

- Усилить визуальный вес главной кнопки (размер/цвет/тень).
- Можно добавить краткую подсказку (например, о правах), но не обязательно.

### 4) Лёгкие анимации (опционально)

- Плавное появление страницы + лёгкое «всплытие» карточек.
- Плавная подсветка выбранного элемента списка (лёгкая, не отвлекающая).
- Кратковременная подсветка новых записей лога.
- Переключение вкладок — лёгкое плавное появление (без резкости).

### 5) Адаптивность и читаемость

- На малых экранах зону логов можно сворачивать или переносить во вкладки.
- Увеличить отступы между полями форм, чтобы снизить тесноту.
- Рекомендуемая иерархия размеров шрифта: заголовки 18/20, текст 14/16, вспомогательный 12/13.

## Чек-лист внедрения (по файлам)

1. `app/components/AppShell.vue`: вес общего макета, переработка header/footer.
2. `app/components/LogPanel.vue`: консольный стиль, статусные бейджи.
3. `app/components/FooterActions.vue`: усиление главной кнопки.
4. `app/components/panels/*`: единая иерархия карточек и система кнопок.
5. `app/components/tabs/*`: единый стиль вкладок.
6. `app/assets/css/tailwind.css`: переменные фона-градиента и стиля карточек.

## Пока не внедряется

- Подключение шрифтов (рекомендации сохранены, загрузка/замена не выполняются).

## Регламент итоговых стилей (рекомендуемая версия)

> Для согласования при внедрении и последующей доработке, чтобы детали не расползались.

### Глобальные переменные (рекомендуемые CSS-переменные)

- `--mtga-bg`: `#F7F8FB`
- `--mtga-surface`: `#FFFFFF`
- `--mtga-surface-soft`: `#F3F6FA`
- `--mtga-border`: `#E5E7EB`
- `--mtga-accent`: `#0EA5A4`
- `--mtga-accent-strong`: `#0891B2`
- `--mtga-warn`: `#F59E0B`
- `--mtga-text`: `#0F172A`
- `--mtga-text-muted`: `#64748B`

### Фон и иерархия

- Фон страницы: лёгкий градиент + лёгкая текстура (не обязательно).
- Фон карточек: белый + тонкая граница + лёгкая тень.
- Скругление карточек: `12px`.
- Внутренние отступы карточек: от `16px`, для сложных панелей можно до `20px`.

### Заголовки и текст

- H1: `text-2xl` + `font-semibold` (главный заголовок)
- H2: `text-lg` + `font-semibold` (заголовок панели)
- Текст: `text-sm` / `text-base`
- Пояснительный текст: `text-xs` / `text-sm` + muted

### Регламент кнопок

- Главная кнопка: `btn-primary` + повышенный контраст (умеренная тень)
- Второстепенная: `btn` + `btn-outline`
- Лёгкая: `btn-ghost`
- Опасные действия: `btn-error` или оранжевый/красный акцент

### Списки и состояние выбора

- Высота элемента списка: `40~44px`
- Состояние выбора: светлая полоса фона + вертикальная линия 3px слева
- Hover: лёгкое «всплытие» фона или светлый оттенок

### Поля форм

- Высота полей ввода: около `40px`
- Отступ между Label и Input: `6~8px`
- Подсказка обязательности: светло-красный текст подсказки

### Регламент LogPanel

- Сверху: заголовок + статусный badge
- Текстовая зона: `font-mono`, фон чуть темнее карточки
- Внутренний отступ: `12px`
- Максимальная высота: `320~360px`

### Регламент Tabs

- Высота tab: `36px`
- Активная: подсветка нижней границы + более насыщенный текст
- Контентная зона: единый padding 16px

### Панель действий футера

- Фиксированная высота: около `64px`
- Главная кнопка справа, слева можно разместить лёгкую подсказку

### Анимации (если используются)

- Загрузка страницы: небольшой переход `opacity` + `translateY` (200~300 мс)
- Выбор в списке: переход `background-color` (150 мс)
- Переключение вкладок: лёгкое плавное появление (150 мс)
